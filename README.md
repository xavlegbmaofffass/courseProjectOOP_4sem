# Frontline: Card Warfare 

**Frontline: Card Warfare** — это тактическая карточная игра для Windows, разработанная в рамках курсового проекта по дисциплине «Объектно-ориентированные технологии программирования и стандарты проектирования»[cite: 1]. 

Главной особенностью проекта является совмещение классической карточной механики с возможностью позиционирования и перемещения юнитов по сетке игрового поля размером 4×3[cite: 1]. Проект демонстрирует применение современных стандартов инженерии ПО, архитектурных паттернов и принципов ООП[cite: 1].

## Ключевые возможности

### Для игроков
*   **Тактические сражения:** Размещение юнитов на поле 4x3, перемещение по клеткам и атака вражеских целей[cite: 1].
*   **Игра против ИИ:** Одиночная кампания против искусственного интеллекта с тремя уровнями сложности (легкий, средний, сложный)[cite: 1].
*   **Конструктор колод:** Создание и редактирование уникальных колод (с проверкой правил: от 20 до 30 карт, ограничение на копии)[cite: 1].
*   **Система аккаунтов:** Регистрация, авторизация и гостевой вход без сохранения прогресса[cite: 1].
*   **Автосохранение:** Автоматическое сохранение состояния игры после каждого хода[cite: 1].

### Для администраторов
*   **Управление контентом:** Добавление новых карт, настройка их параметров (урон, здоровье, дальность, способности) и удаление[cite: 1].
*   **Модерация:** Просмотр статистики игроков и возможность блокировки учетных записей пользователей[cite: 1].
*   **Умный поиск:** Фильтрация и поиск карт по заданным критериям (например, ближний или дальний бой)[cite: 1].

## Технологический стек

*   **Платформа:** .NET 8.0[cite: 1].
*   **Язык программирования:** C#[cite: 1].
*   **Пользовательский интерфейс:** Windows Presentation Foundation (WPF) с использованием языка разметки XAML[cite: 1].
*   **База данных:** Microsoft SQL Server 2022 / SQLite (встроенная БД для локальной работы)[cite: 1].
*   **ORM:** Entity Framework Core (подход Code First)[cite: 1].
*   **Безопасность:** Хэширование паролей с использованием алгоритма библиотеки BCrypt[cite: 1].

## Архитектура и паттерны проектирования

Проект разработан с упором на чистую архитектуру и разделение ответственности:
*   **MVVM (Model-View-ViewModel):** Обеспечивает полное разделение бизнес-логики, данных и пользовательского интерфейса[cite: 1].
*   **Repository:** Реализован слой доступа к данным (UserRepository, CardRepository, DeckRepository) для абстрагирования работы с базой данных[cite: 1].
*   **Command & Observer:** Инкапсуляция действий интерфейса в команды и автоматическое обновление UI через механизм привязки данных WPF[cite: 1].
*   **Strategy:** Использован в `AbilityManager` для обработки различных типов уникальных способностей карт без изменения ядра игрового движка[cite: 1].

## Установка и запуск

Приложение поставляется в виде автономной сборки (Self-contained), что делает процесс установки максимально простым[cite: 1].

1. **Системные требования:** ОС Windows 10 или Windows 11 (64-разрядная архитектура), минимум 200 МБ свободного места на диске[cite: 1]. Доступ к сети Интернет не требуется[cite: 1].
2. Скачайте и запустите исполняемый файл `FrontlineCardWarfare_Setup.exe`[cite: 1].
3. Установка среды выполнения .NET 8 не требуется — все нужные библиотеки уже встроены[cite: 1].
4. База данных (`game.db`) инициализируется, создается и заполняется стартовым набором карт автоматически при первом запуске приложения[cite: 1].
