# Frontline: Card Warfare 

**Frontline: Card Warfare** — это тактическая карточная игра для Windows, разработанная в рамках курсового проекта по дисциплине «Объектно-ориентированные технологии программирования и стандарты проектирования». 

Главной особенностью проекта является совмещение классической карточной механики с возможностью позиционирования и перемещения юнитов по сетке игрового поля размером 4×4. Проект демонстрирует применение современных стандартов инженерии ПО, архитектурных паттернов и принципов ООП.

## Ключевые возможности

### Для игроков
*   **Тактические сражения:** Размещение юнитов на поле 4x4, перемещение по клеткам и атака вражеских целей.
*   **Игра против ИИ:** Одиночная кампания против искусственного интеллекта с тремя уровнями сложности (легкий, средний, сложный).
*   **Конструктор колод:** Создание и редактирование уникальных колод (с проверкой правил: от 20 до 30 карт, ограничение на копии).
*   **Система аккаунтов:** Регистрация, авторизация и гостевой вход без сохранения прогресса.
*   **Автосохранение:** Автоматическое сохранение состояния игры после каждого хода.

### Для администраторов
*   **Управление контентом:** Добавление новых карт, настройка их параметров (урон, здоровье, дальность, способности) и удаление.
*   **Модерация:** Просмотр статистики игроков и возможность блокировки учетных записей пользователей.
*   **Умный поиск:** Фильтрация и поиск карт по заданным критериям (например, ближний или дальний бой).

## Технологический стек

*   **Платформа:** .NET 8.0.
*   **Язык программирования:** C#.
*   **Пользовательский интерфейс:** Windows Presentation Foundation (WPF) с использованием языка разметки XAML.
*   **База данных:** Microsoft SQL Server 2022 / SQLite (встроенная БД для локальной работы).
*   **ORM:** Entity Framework Core (подход Code First).
*   **Безопасность:** Хэширование паролей с использованием алгоритма библиотеки BCrypt.

## Архитектура и паттерны проектирования

Проект разработан с упором на чистую архитектуру и разделение ответственности:
*   **MVVM (Model-View-ViewModel):** Обеспечивает полное разделение бизнес-логики, данных и пользовательского интерфейса.
*   **Repository:** Реализован слой доступа к данным (UserRepository, CardRepository, DeckRepository) для абстрагирования работы с базой данных.
*   **Command & Observer:** Инкапсуляция действий интерфейса в команды и автоматическое обновление UI через механизм привязки данных WPF.
*   **Strategy:** Использован в `AbilityManager` для обработки различных типов уникальных способностей карт без изменения ядра игрового движка.

## Установка и запуск

Приложение поставляется в виде автономной сборки (Self-contained), что делает процесс установки максимально простым.

1. **Системные требования:** ОС Windows 10 или Windows 11 (64-разрядная архитектура), минимум 200 МБ свободного места на диске. Доступ к сети Интернет не требуется.
2. Скачайте и запустите исполняемый файл `FrontlineCardWarfare_Setup.exe`.
3. Установка среды выполнения .NET 8 не требуется — все нужные библиотеки уже встроены.
4. База данных (`game.db`) инициализируется, создается и заполняется стартовым набором карт автоматически при первом запуске приложения.
